# Ax4 SHEQ Agent Operating Rules

These rules apply to every agent drafting, reviewing or researching documents in this repository.

## 1. Scope Discipline

Work only on the assigned document code.

Do not merge multiple controlled documents into one. Policy, manual, procedure, template, form and library documents must remain separate unless the roadmap explicitly says otherwise.

## 2. Jurisdiction

Default jurisdiction is South Australia.

Use Australian English.

Align drafting with:

- Work Health and Safety Act 2012 (SA)
- Work Health and Safety Regulations 2012 (SA)
- SafeWork SA guidance
- Safe Work Australia Codes of Practice, especially asbestos codes where relevant
- Relevant Australian Standards where appropriate

## 3. Ax4 Context

Ax4 Consulting Pty Ltd trades as Ax4 / Ax4 Asbestos Consultants / Ax4 WHS Consultants.

Ax4 is a South Australian asbestos and hazardous materials consultancy. Work includes asbestos inspections, asbestos registers, asbestos management plans, risk assessments, sampling coordination, pre-refurbishment/pre-demolition advice, clearance coordination, contractor liaison and WHS documentation.

## 4. Legal and Defensibility Rules

Never imply that:

- a site is asbestos-free;
- all asbestos will be identified;
- a visual inspection can locate concealed asbestos;
- sampling is always included;
- Ax4 guarantees compliance outcomes;
- Ax4 controls client duty-holder obligations.

Use controlled language:

- so far as is reasonably practicable;
- accessible areas;
- visual inspection;
- limited semi-intrusive where applicable;
- suspected/presumed ACM where not laboratory confirmed;
- client/duty holder remains responsible for implementation.

## 5. Sampling Model

Sampling is not automatic.

Sampling depends on:

- agreed scope;
- site access;
- risk;
- practicality;
- safety;
- client approval where applicable.

For conveyancing/no-sampling reports use wording equivalent to:

> No samples were collected during this inspection. Materials suspected of containing asbestos have been identified based on visual assessment and should be treated as asbestos-containing unless confirmed otherwise.

## 6. Document Type Rules

### Policy

Policy documents state commitment, scope, responsibilities and governance intent. They do not include detailed JSAs, SWMS steps or field checklists.

### Manual

The SHEQ manual explains how the system works and links controlled documents.

### Procedure

Procedures describe how an activity is performed and controlled.

### Template/Form

Templates and forms capture evidence and must be easy to use in the field.

### Library

Libraries hold approved standard wording or coded systems such as limitations and recommended actions.

## 7. Naming and Control

Every controlled document must include:

- document code;
- title;
- version;
- owner;
- approver;
- approval date;
- review date;
- status;
- document history.

## 8. Quality Gate

Before marking a draft ready for review, check for:

- no placeholders unless intentionally marked as template fields;
- no draft artefacts in final content;
- no broken bookmarks or field codes;
- no file path artefacts;
- no client-name contamination;
- no contradictory sampling language;
- no outdated legislation references;
- no unsupported legal claims;
- no unclear responsibility allocation.

## 9. Output Format

Drafts should be written in clean Markdown unless a specific template format is requested.

Use short paragraphs, clear headings and controlled language.

Avoid bloated generic safety content. Keep documents practical for a small consultancy.

## 10. Agent Handoff

Every agent output must include:

1. document code and title;
2. version proposed;
3. assumptions;
4. required linked documents/forms;
5. compliance references used;
6. open questions or unresolved fields;
7. final draft content.
