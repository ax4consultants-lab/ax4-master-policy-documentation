# Logic Loop Boundary — Master Policy Documentation

**Accepted system doctrine:** `ax4consultants-lab/ax4-systems-orchestration/docs/LOGIC-LOOP-OPERATING-DOCTRINE.md`

This repository remains authoritative for controlled AX4 policy, WHS/SHEQ governance, field controls, asbestos technical procedures, forms, registers, limitations libraries and approved wording within its documented scope.

It is **not** the system-wide Logic Loop process registry, runtime authority ledger or agent orchestration authority.

Logic Loop may reference controlled content from this repository as process inputs, constraints, evidence requirements or approved knowledge. Automation must not silently convert a draft policy/procedure into approved operational authority.

For agent-driven work here:

- existing document selection/claim rules remain in force;
- a draft remains a draft until its nominated approval gate is satisfied;
- active Logic Loop process versions are immutable during execution;
- reflection may propose future policy/procedure/process changes but cannot self-approve them;
- historical versions and change records remain evidence;
- capability does not imply authority.

Where this repository's agent instructions and Systems Orchestration address different scopes, both apply. If a system-runtime or authority conflict exists, resolve current authority through Systems Orchestration before execution.
