# Ax4 WHS/SHEQ Documentation Master Roadmap

## Mission

Build a controlled WHS/SHEQ document suite for Ax4 Consulting Pty Ltd that supports South Australian WHS compliance, asbestos and hazardous materials consulting, tender/prequalification submissions, field safety control, technical report defensibility, repeatable document production and future automation through Atom/EchoForge.

## Core Build Logic

Policy sets commitment. The SHEQ Manual explains the system. Procedures define how work is done. SHEP, SWMS and JSA documents control site execution. Forms and registers prove it happened. Libraries standardise wording and automate consistency.

## Build Count

- Core suite: 19 controlled documents
- Mature suite: 25 controlled documents

## Phase 0 — Control Surface

### Purpose

Create the working tree and coordination layer so multiple agents can work without drifting.

### Outputs

- README.md
- MASTER-ROADMAP.md
- DOCUMENT-REGISTER.md
- AGENT-OPERATING-RULES.md
- RESEARCH-BRIEF-TEMPLATE.md

### Acceptance Criteria

- All agents can identify the document suite scope.
- All agents can identify the current build order.
- All agents can work from shared rules.
- No document is created without a code and controlled purpose.

### Requirements

- Pre-start review.
- Client/site briefing.
- Access limitations.
- Inspection process.

- Sampling decision logic.
- Client-approved sampling model.
- Sample collection controls.
- Sample sealing/labelling.
- Decontamination.
- NATA laboratory submission.
- Photo and field note requirements.
- No-access recording.
- Unexpected hazard escalation.

### Critical Update

Remove any wording that implies samples must always be collected. Sampling depends on scope, risk, practicality, safety and client approval where applicable.

# Acceptance Gate for Every Document

A document is not ready for issue unless it passes jurisdiction check, role/responsibility check, asbestos defensibility check where relevant, no overstatement/no guarantee check, document control check, source alignment check, no template artefact check and Auditor review.

---

# Agent Assignment Rule

One document per agent unless explicitly authorised.

Every agent must produce final draft, assumptions, linked documents/forms, compliance references, open questions, version and document-control block.
